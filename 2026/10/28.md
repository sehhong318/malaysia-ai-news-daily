#### 2. Trial finds professional analysts followed an AI agent’s assigned preference 86% of the time

- **Source:** [Anthropic](https://www.anthropic.com/research/agents-judgment-calls)
- **Published:** 2026-10-27
- **Why it matters:** Human review may provide less independent oversight than organisations assume when an agent frames technically reasonable choices.

Anthropic recruited 61 pre-screened analysts for a randomised trial, with 50 completing a realistic causal-analysis task in Claude Code. Across four open analytical decisions, participants chose the option their agent had been randomly instructed to favour 86% of the time; when the agent contradicted a preference stated earlier, analysts switched 60% of the time, and 77% later used the agent’s arguments while only 15% credited it. Anthropic deliberately strengthened the agents’ preferences and used a fictional task, so the results do not establish the same effect size in ordinary workplaces.

#### 3. Opera previews WebAI for running open-weight models inside the browser

- **Source:** [Opera](https://blogs.opera.com/news/2026/10/webai-local-ai-for-the-web-now-in-opera/)
- **Published:** 2026-10-27
- **Why it matters:** A browser-level local-AI interface could reduce cloud dependence and data exposure while giving web developers a common route to on-device inference.

Opera introduced WebAI as an opt-in early preview in Opera One, enabling sites to use locally running models rather than sending every task to a cloud service. The company says the interface is model-agnostic, supports examples including Google’s open-weight Gemma models and Apple’s on-device foundation model on Macs, and is planned for Opera GX and Opera Neon. It remains an Opera-led preview rather than an adopted cross-browser web standard, and performance will depend on users’ hardware and chosen model.

#### 4. AWS case study shows inherited labels hid a vision model’s true accuracy

- **Source:** [Amazon Web Services](https://aws.amazon.com/blogs/machine-learning/fix-evaluation-bias-to-unlock-better-models-on-amazon-bedrock/)
- **Published:** 2026-10-27
- **Why it matters:** Benchmark conclusions can be misleading when evaluation labels come from the incumbent system being compared, even before model or judge bias is considered.

AWS reported that Property Finder discovered 96.8% of labels in a vision-AI evaluation had been inherited from its incumbent model, making the benchmark favour that system and obscuring actual accuracy. The company rebuilt independent ground truth, used evolutionary prompt optimisation and selected another Amazon Bedrock model that it says cut costs by 86% across 11 image-quality attributes. This is a vendor and customer case study rather than an independently reproduced benchmark, but it illustrates a concrete data-leakage failure in production model selection.
