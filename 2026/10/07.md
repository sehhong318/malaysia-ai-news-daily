#### 2. OpenAI will enable detectable ChatGPT text watermarking by default in the EU

- **Source:** [Ars Technica](https://arstechnica.com/ai/2026/10/openai-will-watermark-chatgpt-outputs-by-default-but-only-in-the-eu/)
- **Published:** 2026-10-06
- **Why it matters:** Default provenance marking is a concrete compliance response to the EU AI Act, but limited detector access and easy text modification constrain its usefulness against deliberate evasion.

OpenAI said ChatGPT-generated text will be watermarked by default in the European Union and that users elsewhere can opt in. Its proprietary `textGrain` method encodes patterns in word choice that approved holders of a detection key can test, while OpenAI plans initially to limit detector access to selected researchers and organisations. Ars Technica noted that text watermarks, including this approach, can be circumvented and are not fully reliable, so detection should not be treated as conclusive proof of authorship.

- **Published:** 2026-10-06
- **Why it matters:** A European-trained frontier model with promised open weights could expand sovereign deployment options, but capability and safety claims require independent testing after the weights and fuller documentation arrive.

- **Published:** 2026-10-06
- **Why it matters:** A small model that applies editable natural-language policies without retraining could make real-time moderation more adaptable and auditable, provided platforms test bias, language coverage and edge cases independently.

Musubi released PolicyLM-1.7B under the Apache 2.0 licence, describing it as a decision model that reads a platform's policy alongside each message and returns scores for multiple categories without generating text. #### 7. LibreOffice keeps generative AI out of its default installation

- **Source:** [TechCrunch](https://techcrunch.com/2026/10/06/libreoffice-says-no-ai-is-now-a-software-feature/)
- **Published:** 2026-10-06
