- **Source:** [Cisco](https://newsroom.cisco.com/c/r/newsroom/en/us/a/y2026/m11/cisco-and-openai-launch-shirudo-a-new-project-to-safeguard-agentic-ai.html)
- **Published:** 2026-11-23
- **Why it matters:** The project aims to close the dangerous gap between a vulnerability going public and a patch being deployed — with AI agents writing the stopgap defences themselves.

Cisco and OpenAI have launched Shirudo, an open-source project that helps protect running Linux systems without a reboot while teams roll out a patch. Built on eBPF, a technology that runs small programs inside the operating system kernel, Shirudo lets AI agents scan code and vendor disclosures, trace a vulnerability to the affected assets, and write a small, targeted mitigation — a "shield" — that blocks the vulnerable code path. Every shield is cryptographically signed so the host can verify it before it runs, even if an attacker has gained administrator access. In testing, Shirudo wrote code that detected and blocked attempts to exploit the recent Java4shell and PHP vulnerabilities. The project is at an early stage, and the companies are inviting developers, researchers and enterprises to contribute.
