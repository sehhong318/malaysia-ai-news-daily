#### 1. Meta opens a loss-tolerant RDMA transport for million-GPU Ethernet networks

- **Source:** [Engineering at Meta](https://engineering.fb.com/2026/08/24/networking-traffic/metaroce-rdma-transport-ai-ethernet/)
- **Published:** 2026-08-24
- **Why it matters:** An open transport layer that works on commodity Ethernet could reduce reliance on specialised fabrics as AI clusters scale across data centres.

Meta released the MetaRoCE specification, reference software and compliance suite through the Open Compute Project, moving path telemetry, packet ordering and congestion intelligence into network endpoints. In a 64-node AMD GPU test, Meta reported higher throughput and lower completion times than RoCEv2, about 86% throughput at 1% packet loss and linear scaling across four- and eight-plane topologies. These are developer-run results on the tested cluster, not independent evidence of million-GPU production performance.

#### 2. Microsoft links agent safety tests to portable runtime controls

- **Source:** [Microsoft Command Line](https://commandline.microsoft.com/safety-requirements-failure-paths-assert-acs/)
- **Published:** 2026-08-24
- **Why it matters:** Turning policy into repeatable evaluations and enforceable runtime rules addresses a practical gap between written AI governance and production behaviour.

Microsoft described an open-source workflow combining ASSERT, which generates and traces single- and multi-turn agent tests through OpenTelemetry, with Agent Control Specification controls such as Rego rules and model classifiers. In a synthetic banking demonstration, a generalised authorisation rule reduced violations to zero on the published 72-prompt test set, while separate semantic controls addressed coercive requests. The demonstration illustrates the tooling and is neither a production prevalence estimate nor a broad agent-safety benchmark.

#### 5. SLAC's AI compressor preserves selectable scientific detail at 10–100× smaller sizes

- **Source:** [SLAC release carried by Newswise](https://www.newswise.com/doescience/slac-researchers-develop-ai-based-tool-to-compress-data-without-losing-detail)
- **Published:** 2026-08-24
- **Why it matters:** Controllable compression could make data-intensive instruments usable when storage and transfer capacity cannot keep pace with experimental output.

SLAC researchers reported a neural compression method that uses wavelet analysis to separate features by scale before encoding them, allowing users to preserve fine scientific structure and decompress only a selected region. The method supplements rather than replaces conventional selection and compression, and performance will vary by dataset and desired quality.
